02 / MIRROR + MOON

名字来自镜与月，答案留在尚未说尽的故事里。

Miroon 由 Mirror 与 Moon 组合而来。品牌更深层的叙事内核保存在独立游戏 StellarHush 的内部设定中，对外表达会避开剧情剧透。

STUDIO NOTE / PUBLIC

Mirror 与 Moon，合成 Miroon。

对外，我们不急于解释所有答案。作品、研究与每一次公开进展，会逐渐构成这个名字真正的含义。
